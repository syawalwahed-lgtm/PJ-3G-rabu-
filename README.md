# Misi Olahragawan — PJ Tahun 3

Bahan PdP interaktif untuk tajuk Olahraga Asas: Berlari dan Melompat.

## Kandungan
- `index.html` — aplikasi pembelajaran lengkap (HTML/CSS/JavaScript, satu fail).
- Nota infografik, pautan video YouTube, panduan guru dan 15 soalan kuiz.
- Animasi latar kartun, paparan skor/bintang, bunyi sintesis dan suara Bahasa Melayu jika disokong peranti.
- Mesra telefon/tablet; tidak memerlukan pemasangan atau framework.

## Cara guna
1. Buka `index.html` dengan pelayar web moden.
2. Tekan `Bunyi: OFF` untuk mengaktifkan kesan bunyi dan suara.
3. Baca nota, tonton video, kemudian tekan `Mula Misi`.
4. Untuk video, sambungan internet diperlukan. Suara Bahasa Melayu bergantung pada sokongan suara pada peranti/pelayar.

## Terbitkan di GitHub Pages
1. Log masuk ke GitHub dan cipta repositori baharu, contohnya `pj-tahun3-misi-olahragawan`.
2. Muat naik `index.html` dan `README.md` ke direktori utama repositori.
3. Buka **Settings → Pages**.
4. Di bahagian **Build and deployment**, pilih **Deploy from a branch**, branch `main`, folder `/(root)`, kemudian **Save**.
5. Selepas penerbitan selesai, GitHub akan memaparkan URL laman web pada halaman Pages.
